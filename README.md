# Project Repository: Kit End Date Prediction Case Study

This repository contains the end-to-end pipeline, evaluation, and formal write-up for predicting manufacturing kit completion durations.

## Repository Contents

- **Project Notebook (`.ipynb`):** Contains the complete Python code for loading data, cleaning features, joining supplemental datasets, performing correlation analysis, training machine learning regression models, and plotting evaluation metrics.
- **Case Study Document (`case_study.pdf`):** A formal, chronologically structured PDF report detailing the engineering process, methodology, and modeling outcomes across six distinct phases.
- **Inference Predictions (`inference_predictions.csv`):** A CSV file containing 12,069 continuous duration predictions (in hours) generated by our top-performing Random Forest Regressor model on the inference dataset.

## Core Findings

- **Best Performing Model:** Random Forest Regressor (RMSE: `26.09` hours, R²: `0.5241`).
- **Target Variable:** Continuous hours elapsed from `kit_start` to `kit_end`.
